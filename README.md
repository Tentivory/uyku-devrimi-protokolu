# Uyku Devrimi Protokolü

## Resmi Bildiri

Bu belge, yatak ile insan arasındaki tarihsel sözleşmeyi nihayet kâğıda döken, evrensel nitelikte (ama sadece Türkçe çalışan) bir protokoldür.

Sabah saat 10:00'dan önce ayakta durmak, doğanın düzenine karşı işlenmiş hafif bir suçtur. Bu proje o suçu affeder, kayıt altına alır ve gerektiğinde yorganı tanık gösterir.

## Ne Yapar?

`protokol.py` dosyasını çalıştırdığınızda:

1. Sistem saatinize bakar.
2. Yataktan kalkmanın hukuki durumunu ilan eder.
3. Kaç dakika daha yorgan altında kalmanız gerektiğini ciddi bir tönle hesaplar.
4. Resmi bir ferman basar.

## Kuruluş

```bash
python3 protokol.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz vicdan yeter.

## Anayasa Maddeleri (Kısa)

- Madde 1: Yorgan vatandaştır.
- Madde 2: Alarm, danışma organıdır; icra organı değildir.
- Madde 3: "5 dakika daha" ifadesi süresiz uzatılabilir.
- Madde 4: Çay, protokolün dış işler bakanıdır.
